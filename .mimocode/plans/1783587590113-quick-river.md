# Plan: Banner reactivo al toggle "Envío Automático"

## Estado actual

El mecanismo ya está implementado y **debería funcionar**:

1. **Toggle** (`appointment-reminder-settings.blade.php:51-54`): `wire:change="$dispatch('dispatchToggled', { value: dispatchEnabled })"` — dispatchea un browser event al cambiar.
2. **Banner** (`DispatchBanner.php:18-22`): `#[On('dispatchToggled')]` escucha el evento y actualiza `$enabled`.
3. **Al guardar** (`AppointmentReminderSettings.php:59`): `$this->dispatch('dispatchSettingsChanged')` — el banner también escucha este evento.

## Flujo al hacer clic en el toggle (sin guardar)

```
Toggle cambia → wire:change → $dispatch('dispatchToggled', {value: dispatchEnabled})
                              ↓
DispatchBanner.onToggle() → $this->enabled = params['value']
                              ↓
Re-render → banner aparece/desaparece
```

## Verificación

No se requieren cambios de código. El mecanismo ya está conectado. Para verificar:

1. Ejecutar `composer run dev`
2. Ir a Ajustes → Recordatorios de citas
3. Hacer clic en el toggle "Envío Automático"
4. Observar que el banner en el sidebar aparece/desaparece instantáneamente

Si no funciona, las causas más probables son:
- El `wire:change` no está disparando el evento (verificar en consola del navegador)
- El evento no llega al componente banner (verificar que `#[On('dispatchToggled')]` coincide exactamente con el nombre del evento)
