## Pasos de implementación

### 1. Crear `database/seeders/TwilioContentTemplateSeeder.php`

```php
<?php

namespace Database\Seeders;

use App\Models\TwilioContentTemplate;
use Illuminate\Database\Seeder;

class TwilioContentTemplateSeeder extends Seeder
{
    public function run(): void
    {
        $templates = [
            [
                'nombre' => 'Dos Botones Nuevo',
                'content_sid' => 'HX3e116fa6be92c8ef9db84b65c383d5bc',
                'seleccionada' => true,
                'content_variables' => ['1' => '[NOMBRE]', '2' => '[DIA]', '3' => '[HORA]'],
            ],
            [
                'nombre' => 'Dos botones Antiguo',
                'content_sid' => 'HXdea6aee77629b70b2ca3298e0e2ec5f2',
                'seleccionada' => false,
                'content_variables' => ['1' => '[NOMBRE]', '2' => '[DIA]', '3' => '[HORA]'],
            ],
            [
                'nombre' => 'Confirmar Texto con Emoji',
                'content_sid' => 'HX28712cac47e020331237e0dfb9228aaf',
                'seleccionada' => false,
                'content_variables' => ['1' => '[NOMBRE]', '2' => '[DIA]', '3' => '[HORA]'],
            ],
            [
                'nombre' => 'Confirmar Texto',
                'content_sid' => 'HX94dfe8732cc8177e79e8003da08be354',
                'seleccionada' => false,
                'content_variables' => ['1' => '[NOMBRE]', '2' => '[DIA]', '3' => '[HORA]'],
            ],
        ];

        foreach ($templates as $template) {
            TwilioContentTemplate::updateOrCreate(
                ['content_sid' => $template['content_sid']],
                $template
            );
        }
    }
}
```

### 2. Actualizar `database/seeders/DatabaseSeeder.php`

Agregar línea `$this->call(TwilioContentTemplateSeeder::class);` después de los seeders existentes.

## Archivos a modificar
- `database/seeders/TwilioContentTemplateSeeder.php` (nuevo)
- `database/seeders/DatabaseSeeder.php` (agregar llamada)

## Verificación
```bash
php artisan migrate:fresh --seed
php artisan tinker --execute="dd(App\Models\TwilioContentTemplate::all()->toArray())"
```

## Notas
- Usar `updateOrCreate` para evitar duplicados si el seeder se ejecuta múltiples veces
- El SID `HX3e116fa6be92c8ef9db84b65c383d5bc` queda como seleccionada=true (el template "Dos Botones Nuevo")
